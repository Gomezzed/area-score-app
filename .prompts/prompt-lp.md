### Step 3: LP (src/app/page.tsx) のヒーロー改修

### Step 4: 機能カードのコピー強化
既存3〜4枚の機能カードのコピーを以下方針で強化:

2. 「全国1,916市区町村」: 維持
3. 「CSV・レポート出力」: 維持

### Step 5: 料金セクション改修（最重要）
src/app/pricing/page.tsx と、LP内に料金プレビューがあれば両方を更新:

各プランカードに以下を表示:
- プラン名
- 説明文
- β特別価格を大きく表示: 「¥30,000 / 月」
- 通常価格を斜線小さく表示: 「通常 ¥50,000」
- 「β特別」の小バッジを通常価格の隣に
- 機能リスト
- CTA ボタン

スタイル参考: Google One の価格表示形式（¥1,450/月 と ¥2,900斜線が並ぶ）

プラン詳細:
- Starter (¥30,000 / 通常¥50,000)
  - 説明: 個人事業主・小規模仲介会社
  - 機能: 都道府県・市区町村レベルのエリアスコア / 人口動態グラフ / CSV出力 / 1ID / メールサポート
- Standard (¥50,000 / 通常¥100,000) ★おすすめバッジ
  - 説明: 中堅仲介会社向け
  - 機能: Starterの全機能 / 地図ヒートマップ / PDFレポート / 5ID / メール優先サポート
- Platinum (¥100,000 / 通常¥300,000)
  - 説明: 大手仲介会社・チェーン展開
  - 機能: Standardの全機能 / エリア比較 / 20ID / Slack・Zoomサポート / PDFロゴ対応

各プランCTA: /api/stripe/checkout?plan=starter|standard|platinum

価格セクションの上部または下部に重要な訴求文:
「β期間中のご契約価格は、契約継続中ずっと据え置き。今後の通常価格改定の影響を受けません。」
