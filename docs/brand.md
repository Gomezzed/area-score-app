# AreaScore ブランド / カラートークン規約

サービス名は **AreaScore**（ロゴ・metadata の title / openGraph / twitter・コピーライト表記）。
日本語の説明文中の「エリアスコア」（例：「エリアスコアで可視化」）はプロダクト説明の文言として維持する。
法務ページ本文・REINFOLIB 出典クレジットの文言は**一字一句変更しない**。

## 1. トークン定義の唯一の場所

本リポジトリは **Tailwind v4**（`tailwind.config.ts` は存在しない）。
トークンは `src/app/globals.css` の `@theme` にのみ定義する。

| トークン | 値 | 用途 |
|---|---|---|
| `brand-900` | `#152E4E` | 最暗部（現状ほぼ未使用） |
| `brand-700` | `#1E3F66` | **主色**。塗りボタン・見出しアイコン・強調テキスト |
| `brand-500` | `#2E5480` | hover |
| `brand-300` | `#76A1C8` | 淡い境界・補助 |
| `brand-100` | `#E8EFF6` | バッジ背景・淡い面 |
| `page-bg` | `#F6F8FA` | ページ背景 |

UI のグレーは **Tailwind 標準 slate** で足りる（指定値と完全一致するため独自定義しない）：

| 用途 | 値 | Tailwind |
|---|---|---|
| サーフェス | `#FFFFFF` | `white` |
| ボーダー | `#E2E8F0` | `slate-200` |
| ボーダー（強調） | `#CBD5E1` | `slate-300` |
| テキスト（本文） | `#0F172A` | `slate-900` |
| テキスト（補助・ラベル） | `#64748B` | `slate-500` |
| テキスト（注記・打消し） | `#94A3B8` | `slate-400` |
| カード面 | `#F8FAFC` | `slate-50` |
| 行区切り | `#F1F5F9` | `slate-100` |

例外的に許可するリテラル（トークン化していない）：

| 値 | 用途 | 使ってよい場所 |
|---|---|---|
| `#C7D6E4` | アウトラインボタンの境界 | 全画面 |
| `#FBFCFD` | ダッシュボードのパンくず行の背景 | ダッシュボードのみ |
| `#FAEEDA` / `#854F0B` | **Platinum 機能バッジ**の背景 / 文字 | 下記 §3 参照 |
| `#185FA5` / `#A32D2D` | 増減の**テキスト専用**データ色 | 下記 §5-1 参照 |

**新しい色を発明しない。** 上記以外の色が必要になったと感じたら、まず既存トークンで表現できないか検討し、
どうしても必要ならこのファイルに追記してからコードに入れる。

## 1-1. 対象ルート

ユーザーが到達できるルートは **12**：

`/` `/contact` `/dashboard` `/dashboard/compare` `/dashboard/trade-area` `/help`
`/legal/privacy` `/legal/terms` `/legal/tokushoho` `/login` `/pricing` `/register`

## 2. テーマはライト固定

- `dark:` バリアントと `prefers-color-scheme` は**使用しない**（現状 `src/` に0件）。
- 濃色（`#0F172A` / `#1E293B` / `#334155`）を**背景**として使わない。
  これらは**テキスト色としてのみ**可（`#0F172A` は本文色、`#334155` は入力欄の文字色 / PDF の副題）。
- グラフ（Recharts）のクロームも例外ではない。ツールチップ背景・`CartesianGrid` の `stroke`・
  軸線の `stroke` は inline の JS オブジェクトで指定されており、**クラス名の grep では見つからない**。
  色を洗い出すときは必ずリテラル（16進）でも grep すること。

## 3. バッジの配色

| バッジ | 文字 | 背景 | 使用場所 |
|---|---|---|---|
| Standard+（機能ゲート） | `#1E3F66` | `#E8EFF6` | ダッシュボード右パネルの機能バッジ |
| Platinum（機能ゲート） | `#854F0B` | `#FAEEDA` | ダッシュボード右パネルの機能バッジ |

**`#854F0B` / `#FAEEDA` は「ダッシュボードの機能バッジ」専用。`/pricing` では使用しない。**
料金表はプランを売る画面であって機能ゲートを説明する画面ではないため、ティアバッジを新設せず、
Platinum カードにも固有色を付けない。

`/pricing` のバッジは次の2種のみ：

- **「おすすめ」** … Standard カードのみ。塗り `#1E3F66` / 文字白。
  これはバッジではなく「この画面の主要導線」の一部として扱う。
- **「9/30まで」** … 全カード共通で `#E8EFF6` / `#1E3F66`。

Standard カードの枠は **border 2px `#1E3F66` のみ**で表現する。背景は他カードと同じ白。
影・拡大（`scale`）・背景の色付けで強調しない。通常価格の打消し表記は `#94A3B8`。

> 現状 `#854F0B`/`#FAEEDA` は右パネル（`TownPrioritySection` / `TownHighlightsPanel` /
> `MarketMetricsSection`）に加えて、ダッシュボード配下の `/dashboard/compare` と
> `/dashboard/trade-area` のページヘッダの Platinum バッジでも使用している。
> 同じ「Platinum 機能ゲート」の意味なので現状は許容しているが、厳密に右パネル専用へ
> 寄せる場合はこの2ページの扱いを別途決めること。

## 4. ボタン配色（1画面1塗り）

**1画面につき塗りつぶしは1つまで。** 色で機能を区別しない（旧: PDF=indigo / CSV=緑 / TOP20=黄 …は廃止）。

| 種別 | 配色 |
|---|---|
| 塗り（画面の主要導線1つ） | 背景 `#1E3F66` / 文字白 / hover `#2E5480` |
| アウトライン | 背景白 / 境界 `#C7D6E4` / 文字 `#1E3F66` / hover 背景 `#E8EFF6` |
| 文字のみ | 文字 `#94A3B8` / hover 文字 `#1E3F66` |

画面ごとの塗り：

- ダッシュボードヘッダ … 「注目TOP20」。Free プラン時は排他で表示される「アップグレード」。
  PDF出力 / CSV出力 / エリア比較 / 商圏レポートはアウトライン。ヘルプ / ログアウト / 請求情報を管理は文字のみ。
- LP ヒーロー … 「無料でデモを見る」。「料金を見る」はアウトライン。
  （固定ヘッダの「ログイン / 無料登録」は常時追従するナビ要素として塗りを維持している）
- `/pricing` … Standard の CTA のみ塗り。他プランはアウトライン。
- `/login` … 「ログイン」。「Googleでログイン」はアウトライン。

## 5. 変更してはいけない色（データ色 / 意味色）

見た目の統一より**意味の保持**が優先される。以下はライトテーマ化の対象外：

- **地図マーカー色**（`deltaColor()` / `NEUTRAL_MARKER_COLOR`）と**凡例のドット色**（`DELTA_BUCKETS`）
  … `src/lib/census.ts`。**塗りの値は変更しない。**
- **確定（事実）と推定（ルールベース）の色分け** … 確定=ブランド青帯、推定=橙帯＋「推定」バッジ。
  CLAUDE.md の原則1（確定と推定を絶対に混ぜない）に直結するため、橙の色相は変更しない。
- **推定＝橙系（`#FFF7ED` / `#F59E0B` / `#9A3412`）** … `src/lib/pdf.tsx` の `inferredHead`。
  PDF 内で確定/推定を分離するための意味色。
  **ダッシュボードの Platinum バッジ（`#854F0B` / `#FAEEDA`）とは目的が別であり、相互に流用しない。**
  見た目が似ているからといって統一しないこと。
- **取得優先ランク S/A/B/C/D のバッジ配色**。
- **グラフの系列色**（線・棒の色）。どの系列かを識別する情報を持つ。
- **サードパーティのブランド色**（Google サインインの SVG: `#4285F4` `#34A853` `#FBBC05` `#EA4335`）。
  Leaflet が attribution に実行時注入するウクライナ国旗 SVG（`#4C7BE1` / `#FFD500`）も同様。

### 5-1. 増減のデータ色は「塗り」と「テキスト」を別管理する

同じ増減でも、**面として塗る値**と**文字として読む値**は別の値を持つ。両者を混ぜないこと。

| 用途 | 増加 | 減少 | 定義場所 |
|---|---|---|---|
| **塗り**（地図ピン・凡例ドット） | `DELTA_BUCKETS` の5段階 | 同左 | `src/lib/census.ts`（**変更禁止**） |
| **テキスト**（文字として読む増減率・増減数） | `#185FA5` | `#A32D2D` | `globals.css` の `--color-delta-up` / `--color-delta-down` |

塗り側は5段階のヒートスケール、テキスト側は増加/減少の2値。
テキスト側は白地で 6.5:1 / 7.1:1 を確保しており、`text-delta-up` / `text-delta-down` で参照する。
**テキスト用の値を背景色として使わない。塗り用の値を文字色として使わない。**

適用先は市区町村リストの増減率・増減数、詳細パネルの増減表示と方向アイコン、
町域パネル、地図ポップアップ内の増減率の数値。凡例のラベル文字は `#64748B` のまま。
HTML 文字列内（ポップアップ）からは `var(--color-delta-up)` で参照する
（Leaflet のポップアップは document 内なのでカスタムプロパティが継承される）。

## 6. ロゴ

`src/components/Logo.tsx` を必ず使う。ピンアイコン＋テキストの直書きを復活させない。

- `size`: `sm` / `md` / `lg` = マーク 24 / 30 / 42px
- `variant`: `color`（既定）/ `white`（濃色面の上に置く場合）
- `showWordmark`: 既定 `true`。狭いヘッダでは `false`
- ワードマークは CSS テキスト（`AreaScore` / `letter-spacing: 0.01em` / `font-weight: 500`）
- 画像に `alt="AreaScore"`、ワードマークは `aria-hidden` で二重読み上げを防ぐ

アセット：

| ファイル | 用途 |
|---|---|
| `public/brand/areascore-mark.png` | Logo（color）・PDF のブランドマーク |
| `public/brand/areascore-mark-white.png` | Logo（white） |
| `src/app/favicon.ico` / `icon.png` / `apple-icon.png` / `opengraph-image.png` | App Router のファイル規約で自動配信。metadata に手書きしない |

## 7. 地図ポップアップ

Leaflet のポップアップに付くクラスは **`muni-popup`**（`MunicipalityMap.tsx` の
`bindPopup(..., { className: 'muni-popup' })`）。CSS セレクタもこれに合わせる。

> 過去に `globals.css` 側が `.area-popup` を指したまま放置され、CSS が長期間まったく
> 効いていなかった。クラス名を変える場合は必ず両方を直すこと。

クローム（器）のみライト化する：背景 `#FFFFFF` / 境界 `#E2E8F0` / 本文 `#0F172A` /
ラベル `#64748B` / 閉じるボタン `#94A3B8` / tip も背景と同色 / 影 `0 2px 8px rgb(15 23 42 / 0.12)`。
中身の増減率の数値は `deltaColor()` のまま据え置く。
